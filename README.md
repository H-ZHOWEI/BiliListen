# 哔哩听 BiliListen 🎵

把 B 站收藏夹里的音乐视频**当成 MP3 来听**的安卓 App：后台播放、歌名封面、滚动歌词、车机显示、下载离线，一个都不少。

## 📥 下载安装

> **点这里下载最新安装包：[Releases 发布页](../../releases)** （仓库首页右侧栏的 "Releases" 也能进去）
>
> 直接下载 v1.0 正式版：[BiliListen-v1.0-release.apk](../../releases/download/v1.0/BiliListen-v1.0-release.apk)

安装步骤：
1. 把 APK 传到手机（微信文件传输助手 / QQ / 数据线都行）
2. 点击安装，如提示"未知来源应用"，选择**允许/仍要安装**
3. 打开 App 即可使用

## 🚀 新手操作指引

### 第一步：登录 B 站账号
打开 App 后会进入登录页，两种方式任选：
- **快捷扫码（推荐）**：手机装了哔哩哔哩 App 且已登录 → 点「扫码登录」→ App 会自动唤起哔哩哔哩的扫一扫 → 点**确认授权**，无需输入任何密码
- **网页登录**：点「网页登录」，在弹出的 B 站官方页面里输入账号密码登录，完成后返回

### 第二步：选一个收藏夹
登录成功后自动加载你的收藏夹列表，**点开专门收藏音乐的收藏夹**，里面的视频会变成歌曲列表（歌名、歌手、封面自动识别）。

### 第三步：听歌
- 点任意一首歌开始播放，底部有迷你播放条，点开是完整播放页
- 播放页从左到右：**播放/暂停、上一首、下一首**，支持拖动进度条
- 支持后台播放：切到桌面或锁屏音乐不中断，通知栏/锁屏可控制
- 播放模式：单曲循环 / 列表循环 / 随机播放，可调速

### 歌词说明 📝
歌词按以下顺序自动查找，命中即用：
1. **B 站字幕**（视频自带 CC 字幕或 AI 字幕）
2. **网易云音乐** → **QQ音乐** → **酷狗音乐**（自动按歌名+时长匹配，防止张冠李戴）
3. **LRCLIB** 开源歌词库

播放页找到的歌词会**跟随演唱滚动**。

**歌词对不上进度？（DIY 校准）**
播放页右上角「⋮」更多菜单：
- **校准歌词（从这里开始）**：停在当前位置，选择「后面歌词提前/延后 0.1 或 0.5 秒」——只影响这首歌后面的部分，可多次叠加微调
- **手打歌词**：自己粘贴/输入歌词，每行一句；可以带时间戳 `[00:12.34]歌词`，不带则自动均分
- 手打/校准结果**永久保存在本机**，下次打开依然生效
- **清除我的歌词 / 重置校准**：随时恢复原状

### 车机歌词显示 🚗
- **蓝牙连接车机**：直接可用——App 会把当前歌词行实时写进蓝牙元数据（QQ音乐同款原理），车机上"歌手"位置每句刷新就是歌词
- **Android Auto / 投屏**：歌词同步显示在媒体通知上
- 手机通知栏也能看到当前正在唱的歌词

### 下载离线 📥
- 歌曲列表每行右侧的 **↓ 按钮**：下载这首歌，下次没网也能听
- 下载完成后按钮变成 ✔，再点一下可删除本地文件
- 主界面菜单里可进入「**已下载**」页面统一管理

### 删除/整理收藏 ⚑
- **长按**歌曲列表中的任意歌曲：
  - 「删除」：从收藏夹移除这首歌
  - 「移入待删除」：移到你收藏夹里的"待删除"私密夹（首次使用自动创建），方便之后再统一清理

### 歌词来源偏好
更多菜单里有「**歌词只使用 B 站字幕**」开关：只信 B 站官方字幕、不要网络歌词时打开。

### 软件更新 🔄（v1.1 起支持）
- **自动检查**：每次打开 App 会静默检查 GitHub 上有没有新版本（12 小时最多查一次）
- 发现新版本会弹窗显示版本号和更新内容：**立即更新 / 以后再说 / 跳过此版本**
- 点「立即更新」自动下载并在 App 内直接调起安装（首次会提示打开「允许安装未知应用」，打开后返回再点一次即可）
- 「跳过此版本」后这个版本不再提醒，下个版本照常提醒
- 也可以随时在右上角菜单点「**检查更新**」手动触发

## ❓ 常见问题

**Q：为什么有的歌没有歌词？**
B 站视频没上传字幕、AI 字幕未生成，且网络歌词没匹配到。可以打开视频画面听（播放页会自动切视频模式），或者手动打一份歌词。

**Q：播放失败怎么办？**
音频直链约 2 小时过期，App 会自动重新解析；如果连续失败会自动跳过这首。重新登录一下账号通常能解决。

**Q：歌词匹配错了另一首歌？**
App 已做歌名+时长双重校验；如果仍出现，用「手打歌词」输入正确的即可覆盖。

## 🛠️ 自己编译

```bash
# 要求：JDK 17+，Android SDK
./gradlew :app:assembleDebug     # 调试包
./gradlew :app:assembleRelease   # 正式包（需要自己的签名密钥）
```

- 最低支持 Android 7.0（API 24），目标 Android 16（API 36）
- 技术栈：Kotlin + Media3/ExoPlayer + OkHttp + Coil + ZXing
