# 哔哩听 BiliListen 🎵

把 B 站收藏夹里的音乐视频**当成 MP3 来听**的安卓 App：后台播放、歌名封面、滚动歌词、车机显示、下载离线，一个都不少。

## 📥 下载安装

> **点这里下载最新安装包：[Releases 发布页](../../releases)** （仓库首页右侧栏的 "Releases" 也能进去）
>
> 最新版是 **v1.6**（含历史版本 v1.0 ~ v1.5），在 Releases 页下载即可。
> 版本更新内容见仓库 [CHANGELOG.md](./CHANGELOG.md)。

安装步骤：
1. 把 APK 传到手机（微信文件传输助手 / QQ / 数据线都行）
2. 点击安装，如提示"未知来源应用"，选择**允许/仍要安装**
3. 打开 App 即可使用

## 🚀 新手操作指引

### 第一步：登录 B 站账号
打开 App 后会进入登录页，两种方式任选：
- **哔哩哔哩授权登录（推荐，像微信授权一样）**：手机装了哔哩哔哩 App 且已登录 → 点「哔哩哔哩授权登录」→ App 生成登录二维码并**自动唤起哔哩哔哩** → 在 B 站里「扫一扫 → 相册」选中那张二维码并**确认授权**，无需输入密码，回到哔哩听即自动登录
- **网页登录**：点「网页登录」，在弹出的 B 站官方页面里输入账号密码登录，完成后返回

### 第二步：选一个收藏夹
登录成功后自动加载你的收藏夹列表，**点开专门收藏音乐的收藏夹**，里面的视频会变成歌曲列表（歌名、歌手、封面自动识别）。

### 第三步：听歌
- 点任意一首歌开始播放，底部有迷你播放条，点开是完整播放页
- 播放页从左到右：**播放/暂停、上一首、下一首**，支持拖动进度条
- 支持后台播放：切到桌面或锁屏音乐不中断，通知栏/锁屏可控制
- 播放页左下角**模式按钮**循环切换「顺序播放 → 随机播放 → 单曲循环」，点一下即可切换

**接着上次听（v1.5 新增）**
关掉 App 再打开，上次的播放队列、正在听的那首歌、听到第几秒、播放模式全部原样回来——底部迷你播放条会直接显示那首歌，副标题写着「上次听到 2:31」，点播放就从那儿继续。
默认只恢复不自动出声（免得一开 App 就外放）；想打开即接着播，播放页「⋮」→「启动时自动续播上次的歌」打开即可。

### 歌词说明 📝
歌词按以下顺序自动查找，命中即用：
1. **B 站字幕**（视频自带 CC 字幕或 AI 字幕）
2. **网易云音乐** → **QQ音乐** → **酷狗音乐**（自动按歌名+时长匹配，防止张冠李戴）
3. **LRCLIB** 开源歌词库

播放页找到的歌词会**跟随演唱滚动**。

**歌词置顶悬浮窗（v1.3 新增）**
播放页右上角「⋮」→「歌词悬浮窗（置顶显示）」，会弹窗申请「显示在其他应用上层」权限，同意后屏幕上常驻一个可拖动的歌词药丸，切到任何 App 都能看到当前这句（和音乐软件一样）。关掉即消失。

**语音转文字 / 指定字幕来源（v1.3 新增）**
B 站的 **AI 字幕就是「语音转文字」**——上传者开启后由 B 站服务端自动生成。播放页「⋮」→「字幕 / 语音转文字」可列出视频所有可用字幕轨，手动选某一条（如 AI 字幕）作为歌词来源，下次打开依然生效；选「自动」则恢复默认（优先人工字幕，其次 AI 字幕）。注意：只有上传者开启了 AI 字幕才有，无法本地凭空生成。

**纯音乐不会乱配歌词（v1.3 修复）**
标题含「纯音乐 / 伴奏 / BGM / 轻音乐」等关键词的视频，App 不再去网上盲搜，避免把别的歌的歌词套上来；没有字幕时直接放视频画面。

**歌词对不上进度？（DIY 校准）**
播放页右上角「⋮」更多菜单：
- **校准歌词（从这里开始）**：停在当前位置，选择「后面歌词提前/延后 0.1 或 0.5 秒」——只影响这首歌后面的部分，可多次叠加微调
- **手打歌词（可先选底稿）**：不会直接给你一张白纸——先把这首歌在 B站字幕 / 网易云 / QQ音乐 / 酷狗 / LRCLIB 里的**多个版本**列出来（带歌名、艺人、时长、来源、相近度），挑最接近的那版当底稿，只改错字和偏差时间轴即可
  - 没搜到想要的版本 → 点「换个关键词」，输入原唱歌名 / 动画名 / 歌手名重搜
  - 编辑器里支持带时间戳 `[00:12.34]歌词`，不带时间戳则按行数均分
  - 想换底稿又怕丢改动 → 会先问你「放弃当前修改？」，选「继续编辑」就能保住
- 手打/校准结果**永久保存在本机**，下次打开依然生效
- **清除我的歌词 / 重置校准**：随时恢复原状

### 车机歌词显示 🚗
- **蓝牙连接车机**：直接可用——App 会把当前歌词行实时写进蓝牙元数据（QQ音乐同款原理），车机上"歌手"位置每句刷新就是歌词
- **Android Auto / 投屏**：歌词同步显示在媒体通知上
- 手机通知栏也能看到当前正在唱的歌词

### 下载离线 📥
- 歌曲列表每行右侧的 **↓ 按钮**：下载这首歌，下次没网也能听
- 下载完成后按钮变成 ✔，再点一下可删除本地文件
- 主界面菜单里可进入「**已下载**」页面统一管理

### 删除/整理收藏 ⚑
- **长按**歌曲列表中的任意歌曲：
  - 「删除」：从收藏夹移除这首歌
  - 「移入待删除」：移到你收藏夹里的"待删除"私密夹（首次使用自动创建），方便之后再统一清理

### 歌词来源偏好
更多菜单里有「**歌词只使用 B 站字幕**」开关：只信 B 站官方字幕、不要网络歌词时打开。

### 软件更新 🔄（v1.1 起支持）
- **自动检查**：每次打开 App 会静默检查 GitHub 上有没有新版本（12 小时最多查一次）
- 发现新版本会弹窗显示版本号和更新内容：**立即更新 / 以后再说 / 跳过此版本**
- 点「立即更新」自动下载并在 App 内直接调起安装（首次会提示打开「允许安装未知应用」，打开后返回再点一次即可）
- 「跳过此版本」后这个版本不再提醒，下个版本照常提醒
- 也可以随时在右上角菜单点「**检查更新**」手动触发
- 若「立即更新」提示下载失败（多因 GitHub 安装包 CDN 在部分网络下被墙/限速），弹窗会提供「浏览器下载」按钮，用手机浏览器打开 Release 页手动安装即可；v1.3.1 起还会自动尝试国内镜像加速

## ❓ 常见问题

**Q：为什么有的歌没有歌词？**
B 站视频没上传字幕、AI 字幕未生成，且网络歌词没匹配到。可以打开视频画面听（播放页会自动切视频模式），或者手动打一份歌词。

**Q：播放失败怎么办？**
音频直链约 2 小时过期，App 会自动重新解析；如果连续失败会自动跳过这首。重新登录一下账号通常能解决。

**Q：这是爬虫吗？爬的是视频还是音频？怎么"绕过"B站反爬的？**

不是爬虫，也没有绕过任何东西——它是一个**按规矩办事的第三方客户端**，原理和你用浏览器看 B 站完全一样：

1. **不是爬虫**：爬虫是指批量抓取全站数据。本 App 只调用 B 站官方客户端/网页在用的接口，读取**你自己账号**的收藏夹，请求量和人工浏览相当，不做任何批量抓取。
2. **只要音频**：B 站视频底层是 DASH 格式（音轨和画面是分开的两条流），网页播放器本来就是分开加载的。App 调 `playurl` 接口后**只取音频那条流**（m4s），画面一条都不碰。
3. **没有"绕"反爬**：那些所谓的反爬措施，正常客户端本来就要做——
   - WBI 签名：B 站网页端自己的参数签名算法，浏览器每次请求也在算，App 按同样算法生成而已
   - Referer / 浏览器 UA：浏览器发请求时自动带的标准头
   - Cookie：来自**用户本人扫码授权**的官方登录接口（passport），和网页版登录没区别
4. **边界**：只访问自己账号有权访问的内容；音频直链约 2 小时就过期，说明这是"实时按需获取"而非缓存盗链。

**Q：会不会封号？**
App 只读取你账号能看的内容、请求频率与正常使用一致，不刷量不点赞不碰隐私接口。但任何第三方客户端理论上都存在平台策略变动的风险，介意请自行斟酌。

**Q：歌词匹配错了另一首歌？**
- 纯音乐/伴奏类视频：App 已自动跳过网络盲搜，不会再把别的歌歌词套上来（见上文）。
- 普通歌曲仍串味：App 已做歌名+时长双重校验；可用「手打歌词」输入正确的覆盖，或在「⋮ → 字幕 / 语音转文字」里指定正确的字幕轨。

## 🛠️ 自己编译

```bash
# 要求：JDK 17+，Android SDK
./gradlew :app:assembleDebug     # 调试包
./gradlew :app:assembleRelease   # 正式包（需要自己的签名密钥）
```

- 最低支持 Android 7.0（API 24），目标 Android 16（API 36）
- 技术栈：Kotlin + Media3/ExoPlayer + OkHttp + Coil + ZXing

## ⚠️ 使用须知

- 本项目仅供**个人学习交流**，请支持正版音乐
- 所有数据（登录态、歌词 DIY、下载）均保存在本机，App 不上传任何用户数据
- B 站相关功能依赖官方接口，如接口变更请提 Issue
